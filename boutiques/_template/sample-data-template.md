# Boutique Data Sheet

> **How to use this sheet**
>
> 1. Ask the tech team to create the boutique's folder (they run `npm run new-boutique "Boutique Name"`), or copy this `_template` folder yourself and rename it to the boutique's name in lowercase with hyphens, e.g. `boutiques/sri-lakshmi-designers/`, then rename this file to `data.md`.
> 2. Fill in every field you can. Write the answer after the colon, on the same line. Don't change the labels.
> 3. Fields marked **★** are required. Without them we cannot build the demo.
> 4. If you don't know something, write `NA`. Don't delete the line.
> 5. Put all photos and the logo in the `photos/` folder, named exactly as shown in Section 9: lowercase, no spaces, JPG or PNG. iPhone photos must be JPG, not HEIC (on the iPhone: Settings → Camera → Formats → Most Compatible).
> 6. Write names and text exactly as the boutique uses them (same spelling and capitals as on their board).
